Сравнение АН между периодами

Чтобы построить сравнительный отчёт между несколькими периодами:

1️⃣ Перейдите во вкладку 📚 Архив АН
2️⃣ Поставьте галочки на 2-4 файлах, которые хотите сравнить
3️⃣ Нажмите кнопку «📑 Сравнить выбранные»

После этого здесь появятся графики бок-о-бок: KPI, акты по типам, массы, участки, топ дефектов, критичность и другие показатели по каждому периоду отдельно.

Загрузите файл рекламаций (выгрузка из 1С:ДО)

Или выберите готовый файл из вкладки «📚 Архив Претензии»

Сравнение с прошлым годом
Можно выбрать сразу несколько файлов (в окне выбора удерживайте Ctrl или Shift) —
например, «2026.xlsx» и «2025.xlsx». Или загрузите одну выгрузку за оба года.
Уже загрузили текущий год? Кнопка «➕ Добавить год» над отчётом добавит второй файл.

Сравнение ВХ между периодами

1️⃣ Перейдите во вкладку 📚 Архив ВХ
